# 🚚 Delivery Route Optimization Mini Project

## 📌 Overview
This project applies multiple algorithm design techniques to optimize delivery routes for a logistics system. It considers constraints like distance, parcel value, and vehicle capacity.

---

## 🧠 Concepts Used

### 🔹 Recursion
- Route cost calculation (TSP-like)

### 🔹 Greedy Algorithm
- Parcel selection (value/weight optimization)

### 🔹 Graph Algorithms
- Dijkstra (shortest path)
- Prim’s (network design concept)

### 🔹 Dynamic Programming
- Time-window validation (conceptual)

### 🔹 NP-Hard Problem
- Travelling Salesman Problem (TSP)

---

## 🛠️ Tech Stack
- Python 3
- Heapq
- Itertools
